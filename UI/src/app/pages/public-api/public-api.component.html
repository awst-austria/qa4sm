Public API

The QA4SM Public API enables programmatic access to the service from the command line or custom scripts. It supports upload of user datasets, submission of validation jobs, monitoring progress, and download of validation results. Access is authenticated with a personal token.

You can request a personal API token from your User Profile page.

Python client

For Python users, the qa4sm-api package provides a client library and a command line tool for the most common tasks: searching datasets, downloading validation configurations, starting validations, and downloading results. 

$ pip install qa4sm-api
$ qa4sm api setup      # stores your API token in ~/.qa4smapirc
$ qa4sm --help
Copy

See the package documentation for more examples. The examples below use plain curl and work without any installation.

Usage

Here are some examples of how to use your personal API token to interact with the service. Each request must include your token in the Authorization header.

Upload your own dataset:

The file (.nc, .nc4, or .zip with CSV files) must follow the upload guidelines. dataset_name and version_name are required (up to 30 characters each); optionally, dataset_pretty_name and version_pretty_name can be added. After preprocessing, the dataset appears on the My datasets page and can be used in validations. 

$ curl -X POST \
-H "Authorization: Token <YOUR_USER_TOKEN>" \
-F "file=@<FILE>" \
-F 'metadata={"dataset_name":"<DATASET_NAME>","version_name":"<VERSION_NAME>"}' \
https://qa4sm.eu/api/upload-user-data-with-token/<FILE>
Copy

Replace <FILE> with the file name (e.g. my_data.zip) in both places. A successful upload returns HTTP status 201. Uploads are limited to 20 per hour.

Submit validation:

<CONFIG_JSON_FILE> is a JSON file that defines the datasets, filters, time ranges, and metrics for your validation job. 

$ curl -X POST \
-H "Authorization: Token <YOUR_USER_TOKEN>" \
-H "Content-Type: application/json" \
-d @<CONFIG_JSON_FILE> \
https://qa4sm.eu/api/start-validation-with-token
Copy

List your validation runs:

$ curl -X GET \
-H "Authorization: Token <YOUR_USER_TOKEN>" \
https://qa4sm.eu/api/my-validation-runs-with-token | jq -r '
.validation_runs[] |
[.id, .name, (.datasets | join("; ")), .progress] |
@tsv
' | column -t
Copy

Download results (ZIP):

$ curl -X GET \
-H "Authorization: Token <YOUR_USER_TOKEN>" \
"https://qa4sm.eu/api/download-result-file-with-token/<VALIDATION_RUN_ID>/zip" \
--output <OUTPUT_FILE>.zip
